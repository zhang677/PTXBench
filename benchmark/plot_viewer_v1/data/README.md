# Plot-viewer data

`experiments.csv` is the canonical set of 105 non-Triton evaluation-run
directories collected from the structured `three-prompt-results` artifacts. It
is the exact union of `counts-sass-usage-3-prompt/experiments_hopper.csv` and
`counts-sass-usage-3-prompt/experiments_blackwell.csv`: 85 Hopper runs and 20
Blackwell runs.

The four experiment-backed CSVs in this directory contain exactly those 105
`exp_dir` values. Correctness, speedup, and reasoning exports include all
available trajectories in each run. The verified-SASS export reads each run's
canonical dynamic SASS evidence from `turn_correctness_sass_arch.csv`, as
generated by the `counts-sass-usage-3-prompt` workflow.

The model, PTX, and FlashAttention release-date CSVs are reference metadata and
do not add experiments to the viewer.
